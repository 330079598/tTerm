# 021 后置非主体终端功能

- 日期：2026-11-27
- 决策人：stone
- 状态：已决定

## 背景

GPUI 主体终端使用路径（本地/SSH 会话、输入输出、滚动与搜索、剪贴板、工作区）仍在验收和补齐。串口终端与日志回放目前只有共享 core 能力或尚未有完整原生界面，但它们不影响主体终端和工作区的日常使用。若在 G2 前强行实现，会把有限的验收时间从核心路径分散出去。

## 决定

1. 串口终端（P2-20、P4-10）和会话日志/回放（P2-18、P4-11）后置到 G2 主体终端验收之后。
2. 后置表示暂不作为 G2 主体使用的阻塞项，不表示明确放弃；功能矩阵继续标记为“未开始”，直到有可操作 GPUI 界面和独立验收证据。
3. 后置期间不删除、不改变 Tauri 版和 core 中已有的串口、日志与回放能力，也不改变共享数据格式。
4. 后置功能开始实现时，仍须按原任务卡补齐界面、双端行为、平台范围和验收证据，再参与 P4-27/G4 的完整对齐判断。

## 影响与风险

- G2 的主体验收优先覆盖本地/SSH 终端、输入输出、滚动、搜索、剪贴板、快照恢复、输入法、性能和稳定性；串口与日志回放不作为本阶段通过条件。
- P4-27 仍不能签收，因为“未开始”允许后置但不能绕过功能矩阵；进入 P5-04 前仍需完成这些功能或取得另行的明确放弃决策。
- 串口和日志回放的后置不影响当前工作区、连接库和设置页的实现顺序。
