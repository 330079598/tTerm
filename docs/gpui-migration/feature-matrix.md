# 功能矩阵

本表逐一对照现有 Tauri 版的功能与 GPUI 版的原生实现，用于判断 P4 是否完成、G4 是否可以切换。模板由 W0-02 建立，[P4-27](p4-features.md#p4-27-功能对齐审核) 负责填满。

| 功能 | 现有实现位置 | 原生实现位置 | 状态 | 验收证据 |
| ---- | ------------ | ------------ | ---- | -------- |

## 状态

| 状态     | 含义                               |
| -------- | ---------------------------------- |
| 未开始   | 原生版还没有对应实现               |
| 进行中   | 已有实现，尚未达到与现有版一致     |
| 对齐     | 行为与现有版一致，验收证据可以复现 |
| 明确放弃 | 决定不在原生版实现，需要决策人确认 |

- **未开始**与**进行中**的项由 P4-27 在填表时列出；“进行中”附剩余工作或链接到报告。
- **对齐**的项必须在“验收证据”列给出对照测试、录屏或截图路径，只写“已实现”不算证据。
- **明确放弃**的项必须有决策人确认。按[验收协议第 4 节 G4](acceptance.md#g4-正式切换)的要求逐项批准，确认记录写入 `decisions/`，本表保留该行与理由。

## 填写

- “现有实现位置”写 `src/` 中的组件目录或模块路径，必要时到文件。
- “原生实现位置”写 `crates/` 中的 crate、视图或模块路径。
- 功能划分参考 `src/components/` 的功能目录与 `src/i18n/locales/en.json` 的文案分组，至少覆盖设置页的每个设置项。
- P4-27 完成后，本表没有“未开始”；每个“对齐”都有证据。
