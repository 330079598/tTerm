| ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | ----------------------------- | -------------------------------------------------- |
| 重启后续接 AI 会话（[N-01](new-features.md#n-01-重启后续接-ai-会话)、[决策 009](decisions/009-agent-session-resume.md)） | `src-tauri/src/core/agent_resume.rs`（校验、转义、构造命令）；`src-tauri/src/agent_integration/`（钩子报告会话 ID 与目录）；`src/lib/agentStatus.ts`、`src/lib/agentResumeCwd.ts`（标签归属）；`src/types/tab.ts`（可选保存字段）；`src/components/TerminalTab/agentResume.ts`、`AgentResumeBar.tsx`（自动与手动续接）；设置开关在 `GeneralSettingsTab.tsx`（dev 分支，合入提交 `1aed8dee`） | `crates/tterm-terminal/src/session_reports.rs`（OSC 7/9;9/133/633/777 有界扫描）；`crates/tterm-gpui/src/terminal_demo/session/reports.rs`（报告邮箱、提示符实时信号、丢报标记）；`crates/tterm-gpui/src/terminal_demo/window/agent_resume/`（捕获、等待、自动与手动续接）；共享 `crates/tterm-core/src/core/agent_resume.rs` 与 `agent_status.rs`；保存字段 `agentResume` | 进行中 | GPUI 版已实现并通过单元测试；Windows 本地与 SSH 手工验收未做；开关读取 `resume_agent_sessions`（默认开启），UI 开关待 P3-02 配置保存与 P4 设置页 | [N-01 报告](reports/N-01.md) 的 GPUI 小节 |

## 状态

| 状态     | 含义                               |
| -------- | ---------------------------------- |
| 未开始   | 原生版还没有对应实现               |
| 进行中   | 已有实现，尚未达到与现有版一致     |
| 对齐     | 行为与现有版一致，验收证据可以复现 |
| 明确放弃 | 决定不在原生版实现，需要决策人确认 |

- **未开始**与**进行中**的项由 P4-27 在填表时列出；“进行中”附剩余工作或链接到报告。
- **对齐**的项必须在“验收证据”列给出对照测试、录屏或截图路径，只写“已实现”不算证据。
- **明确放弃**的项必须有决策人确认。按[验收协议第 4 节 G4](acceptance.md#g4-正式切换)的要求逐项批准，确认记录写入 `decisions/`，本表保留该行与理由。

## 填写

- “现有实现位置”写 `src/` 中的组件目录或模块路径，必要时到文件。
- “原生实现位置”写 `crates/` 中的 crate、视图或模块路径。
- 功能划分参考 `src/components/` 的功能目录与 `src/i18n/locales/en.json` 的文案分组，至少覆盖设置页的每个设置项。
- P4-27 完成后，本表没有“未开始”；每个“对齐”都有证据。
