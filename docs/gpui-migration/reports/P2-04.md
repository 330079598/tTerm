### 行为

- 单击开始 Simple selection；双击选词；三击选行。Control 开始的单击使用矩形选择；macOS 之外的 Alt 也按现有 pointer policy 选择矩形。
- 应用请求鼠标上报时，左、中、右键按 1000/1002/1003 的既有协议路由；1002 只上报按住按钮时的移动，1003 会上报悬停；支持 legacy 与 SGR 1006 编码。
- Shift 强制本地选择并扩展现有选区。macOS Option 只在 `macos_option_forces_selection` 策略开启时强制选择，其他平台不受该策略影响。
- Linux 中键通过 primary selection 调用 `paste_text`，沿用普通粘贴的换行与 bracketed-paste 处理；其他平台不启用该路径。
- 词选择使用 xterm 接入的 word separators。宽字符位于行尾时继续到 wrapped 下一行，分隔符位于 wrap 边界时不会误合并两个词。
- 语义选择以 Alacritty 跟踪的原始词作为 anchor。拖拽目标词单独记录，显示和复制每次从 anchor 与当前目标词重建，因此拖回较短范围或越过 anchor 都能收缩、反向。
- `write`、`resize` 和 `set_scrollback` 改变网格生命周期时，活动 word drag 的 endpoint 会被丢弃，anchor 保留。下一次 pointer move 才重新建立扩展范围；松手不会把旧屏幕坐标写回选区。
- 输出流中的 OSC 133/633 type A prompt mark 会在精确字节位置触发 mouse reporting 检查。guard 先应用 mark 前的字节，再在仍开启时写入 Tauri 版一致的 OFF 序列，然后继续应用同一 batch 的后续字节。
- 没有 prompt mark 时，本地 PTY 在输出安静 200 ms 后检查 shell 是否已回到前台。foreground 回答必须匹配 output epoch、session nonce 和 live flag；prompt mark 不需要等待 foreground probe。
- foreground process probe 只用于已知本地连接。SSH、serial 和未知连接类型仍可在 prompt mark 后关闭 mouse reporting，但不会查询本机进程。

精确 OFF 序列为：

```text
\x1b[?9l\x1b[?1000l\x1b[?1001l\x1b[?1002l\x1b[?1003l\x1b[?1005l\x1b[?1006l\x1b[?1015l\x1b[?1016l
```

## 偏差

1. 活动 word drag 在 output、resize 或 scrollback 变化时采用保守行为：取消旧 endpoint，保留 anchor。这样不会把旧屏幕坐标写回错误范围；用户需要继续拖动一次才会恢复扩展选区。
2. Ctrl+C 压力测试曾在 session 89916 超时；同测试程序独立运行和后续全仓测试均通过。原因尚未完全归因，继续保留测试与原预算。
