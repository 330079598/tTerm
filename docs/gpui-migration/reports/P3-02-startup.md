# P3-02：启动配置与 Windows 工作区参照

GPUI 启动时先严格读取本地配置，再用共享 `normalize_config` 生成所有视图使用的快照。不会因为打开窗口而重写配置；读失败时采用归一化后的默认值。此批没有新增通用设置订阅，也没有把 React 标签栏当作 GPUI 标签栏交付。

## Windows 原生窗口复核

调试构建可在启动前设置 `TTERM_GPUI_CHECK_INSTANCE` 为未使用的无符号整数。应用在临时目录下为该编号单独保存配置和数据库，并使用独立的凭据服务名称。重启复用同一编号；不设置时继续使用通常的 `gpui-dev`。不要在日常会话里做缩容验收。

- 用真实本地 PTY 输出 150 行编号，滚动到第 44 行。将编辑框从 `10000` 改为 `24` 后取消；视口仍从第 44 行开始，再次打开为 `10000`。
- 在同一会话保存 `12000` 后，视口不跳动。核对隔离配置文件，正常退出，再用同一编号启动新进程，编辑框读回 `12000`。
- 首次检查发现深色背景上的标题和字段标签几乎不可见。改用主题前景色后，重启窗口复核通过。
- 本次没有在原生窗口中执行会淘汰旧历史的保存。运行中缩容由已有的会话/模型测试覆盖，仍需原生视口验收；本记录不关闭 P2-06 或 P3-02。

## 标题栏对照

`workspace.titlebar.default` 是 Windows 标题栏的 **React 侧参照**：两个模拟本地终端标签，一个选中；不建立连接。它不是整个工作区截图，也不参与现有 GPUI 像素比对。其余 B1～B4 场景和原生多会话标签栏待做。
