# P3-02 第一批：运行中的终端设置

这批以回滚行数为例，串起原生设置、配置文件和已打开的会话。它不是整张 P3-02 的验收，也不取代 P2-06 的滚动交互验收。

- 原生窗口继续从隔离的 `gpui-dev` 目录读取配置。修改回滚行数时在后台更新 `config.json`，沿用 Tauri 的字段名和 `0` 表示无限的约定，只写这一项，不用启动时的快照覆盖后来修改的其他项。
- 缩小容量会淘汰历史行，不能靠事后回滚恢复。因此只在文件成功保存后发布变更，失败不改变当前会话。会话管理器更新已有模型与新会话默认值；可见终端即使暂时没有新输出，也会收到重绘通知。
- 配置文件测试覆盖两个客户端共用的读写格式、未知字段和损坏文件；GPUI 与会话测试分别覆盖保存通知、正在显示的历史、视口与缓存失效，以及新开会话继承设置。

2026-11-21 Windows 自动化验收：六项 pnpm 检查、Rust fmt、严格 workspace/all-targets Clippy 与 `cargo test --workspace` 全部通过。GPUI 编辑器用例覆盖非法输入、取消、保存与焦点恢复；另有真实本地会话用例覆盖保存后缩容、切换无限和保持同一会话。已有的两项 `io_batcher` 时序测试在与前端测试并行时超时，前端结束后原样重跑完整 Rust 套件通过；未修改阈值。

后续：在 Windows 原生窗口复核编辑、取消、缩容时正在查看的历史，以及重新启动后的值。P3-02 的其余配置订阅、活动状态与退出阻塞项，以及 W0-05 B1～B4 的对照基线，均不在本批。
