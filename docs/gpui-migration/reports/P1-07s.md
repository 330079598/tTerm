## 偏差

- 计划示意要求 `FileDrag` 从 `MainWindow` 组装，但 `tterm-platform::native::drag::NativeFileDrag` 的构造参数是 `Arc<dyn WindowHost>`，而 `MainWindow` 不实现 `WindowHost`。因此平台初始化为 `main_window` 和 `window_host` 各创建一个 Tauri 窗口适配器；两者都只持有同一个 `AppHandle`，不改变行为。无需新增 trait，建议后续 P1-08/P1-09 若要共享底层适配器再统一接口。
- `SecretStoreState` 按现有定义保留值类型；其内部状态本来就是可 Clone 的共享句柄，符合计划字段类型，不额外包 `Arc`。
- P1-07s 没有迁移任何 command 读取方；单独 `manage` 保留给 a–d/e 的后续卡。
