# P0-24 UI 原语还原验证

## 结论

本轮按评估意见改走 tterm-ui 令牌自绘。gpui-component 仅保留 Input 的编辑行为状态机，不使用其主题。Button 与 Input 已有独立 parity 夹具；Button 拆为 `ui.button.variants` 和 `ui.button.sizes`，两屏均完整落在 800×600 Windows 视口内。对比工具现已按元素有效 opacity 合成颜色并记录样式；组件绘制与快照共用同一结构。最新 compare 仍发现 GPUI 子控件内部颜色与浏览器合成存在差异，故按规则停止并保留热力图。

## 首次尝试与改走自绘

首次尝试封装 gpui-component：默认主题使 outline/secondary 变成白底黑字，Button 仅一行 6 个控件，未覆盖 React 的 8 种尺寸、图标按钮和状态；首次深色结果 Button full SSIM `0.763262`、masked SSIM `0.843661`，Input full SSIM `0.813599`、masked SSIM `0.857887`。放弃理由是默认主题与生产 CSS 差异过大，逐项覆盖代价高且会影响其他组件。

自绘实现直接使用 tterm-ui 的 HSL 令牌绘制尺寸、内边距、圆角、边框、颜色、字重和 focus/hover/disabled 状态；Input 的文字编辑仍由 gpui-component InputState 提供，但外观由 tterm-ui wrapper 绘制，因此没有全局主题覆盖。

## 主题隔离

自绘 Button/Input 只读取 tterm-ui 令牌，不修改 gpui-component 全局主题。渲染 API 要求显式传入 `Colors`，因此不存在局部全局主题覆盖路径。自动化 SHA-256 前后回归仍待补充。

## 输入测试与人工项
