# 从空连接库连接第一台 SSH 主机（macOS，2026-11-26）

这是 P4-01、P4-02、P4-04 的首个可用流程，不是三张整卡签收。

1. 在隔离 GPUI 实例从标题栏 **SSH → 新建连接** 输入名称、主机、端口、用户名，选择密码认证。保存后返回列表，选中刚创建的记录；按 **打开** 发起连接。保存本身不拨号，也不存登录密码。
2. 用隔离 Tauri 实例的「已保存连接 → 新建连接 → SSH」保存相同输入。读取两端 SQLite 中的 profile，排除各自产生的 ID 后，本例基础连接的字段值一致。
3. 目标是仅通过本机回环地址开放的临时 Linux OpenSSH 容器。首次连接显示的 ED25519 指纹与容器内独立读取的指纹一致。测试中一次密码提示超时，连接失败；从列表重新打开后输入临时密码登录成功，实际命令返回 `FIELD-ONE-field-field-ssh-44`。隔离库此时有一个 profile、一条主机记录、零条 secret。
4. 退出远程 shell，编辑原记录，改为一次性 ED25519 私钥路径，再次打开连接。不再提示信任相同主机；远程命令返回 `FIELD-KEY-field-field-ssh-56`。两次分别经密码、公钥认证，不是本地命令或回放。

附加回归覆盖：编辑后保留未展示的配置、无效字段不保存、未确认不建立主机信任、指纹变化时取消不覆盖旧记录、加密 OpenSSH 私钥的非回显口令提示。桌面私钥用例使用未加密的临时密钥。

与 Tauri 的差异仍包括连接分组和搜索、SSH 配置导入、更多认证与高级连接设置，以及独立的认证对话框。此次只对照基础流程与数据，没有签收像素一致性或其他平台。
