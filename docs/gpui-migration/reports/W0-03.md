## 遗留问题

- **P0-16 与 P0-17 缺少环境。** 两者都是 P0 的停止条件：P0-16 的四个 Linux 输入法组合全部缺失；P0-17 的 Windows、Linux 无 GPU 环境与 RDP 全部缺失。G1 时需要决策人决定补建环境后再验证，还是带着“未验证”进入 P1。`environments.md` 2.2 与 4.1 节写了不增加硬件、只用本机 VMware 补建的方法。
- **vtebench 未克隆。** P0-01 开始时在两台机器上克隆，并把路径补进 `environments.md`。
- **Mac 的 agent 会话没有屏幕录制权限。** 真实窗口截图仍由人手工截取；授予权限后可以自动化，W0-05 与 P0-24 的交叉核对会用到。
