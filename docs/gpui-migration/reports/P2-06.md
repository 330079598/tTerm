# P2-06：回滚容量首批

Windows，2026-11-21。Pi（`magpie/auto/deepseek-v4.1-flash`）返回候选补丁，主控按固定版本 Alacritty 的 `set_options` 与 `Grid::update_history` 审查后接入。

- 新建 GPUI 会话使用已保存的 `scrollback_lines`。复用 core 解析显式上限和 `0` 哨兵；Alacritty 的行存储按需增长，不会在启动时按上限分配。
- 模型原有的 `set_scrollback` 不重建会话。缩容淘汰历史行时现在会使绝对行缓存失效；备用屏幕无法观察隐藏主屏幕的历史，因此缩容时保守失效。上游已校正显示偏移，不重复实现。
- 模型回归覆盖增长、同值、缩小但无淘汰、顶部视口与隐藏主屏幕。尚未接入运行时设置变更通知或完成概览标记、清除后的内存验证、原生滚动交互验收；不将本批视为整卡通过。
