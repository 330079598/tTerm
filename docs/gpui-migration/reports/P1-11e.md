# P1-11e 快捷键纯逻辑移植到 Rust（macOS）

## 结论

完成：快捷键核心逻辑已移植到 `crates/tterm-core/src/keymap/`，69 个 TypeScript 用例已逐条转写到独立 Rust 测试文件，并通过 tterm-core 测试。

## 改动

- `crates/tterm-core/src/keymap/actions.rs`：47 个动作、动作分组及可编辑区域策略。
- `crates/tterm-core/src/keymap/chord.rs`：按键描述输入结构、物理 code 归一化、Unicode 安全的 Rust 字符串处理、解析/序列化、macOS/Windows-Linux 显示格式。
- `crates/tterm-core/src/keymap/config.rs`：默认绑定、macOS 覆盖、配置规范化、冲突检测、索引、CLI 冲突提示和字符串配置反序列化。
- `crates/tterm-core/src/keymap/actions.rs`：有序分组 `KEYMAP_ACTION_GROUPS`、字符串分组 id 与 `get_actions_by_group`。
- `crates/tterm-core/src/keymap/dispatcher.rs`：抑制层、打开浮层、编辑区域、macOS Ctrl 回退及消费规则。
- `crates/tterm-core/src/keymap/mod.rs` 与 `crates/tterm-core/src/lib.rs`：模块导出。
- `crates/tterm-core/Cargo.toml`：使用 workspace 已有版本的 `serde` 与 `serde_json`。
