## 当时派发的实现卡：P2-19 第一批，只读兼容

此批已在 `43bf05bd` 实现，见[普通启动回归和验收边界](P2-19-read-only.md)。上表是派发前的核查记录，不代表当前仍缺只读恢复。

1. 用旧版生产序列化入口和锁定的 SerializeAddon 生成小型合成 fixture。保留生成命令、版本、滚出屏幕的一行、SGR 颜色及预期可见内容。不读取真实用户的会话文件。
2. 在临时数据根写入旧版格式的标签和 `<tab-id>.gz`，先写一个能暴露缺口的**普通启动**测试。用生产恢复路径验证内容归属原标签、颜色和历史、恢复标识及其后的新会话输入输出；无快照或损坏时新会话仍可用。
3. 历史内容不能作为实时输入重放：验证不会写 PTY、发送查询回包、改标题、触发通知或写剪贴板；另测显式 `--exec` 不导入旧内容。不覆盖源快照，不在此卡决定原生保存格式。
4. 视觉记录、设备长跑、无 GPU 实机测量独立排期；需要专用桌面的项不能阻塞这张只读兼容卡。若要改变写入格式、降级支持或签收 G2，另请决策人确认。
