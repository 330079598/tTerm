## 偏差

1. **目录已存在。** 卡上写“创建 `docs/gpui-migration/reports/`、`docs/gpui-migration/decisions/`”，实际这两个目录已由 W0-01 建立，内有 `reports/W0-01.md`、`decisions/001-formal-migration.md` 与 `decisions/006-w0-01-ci-waiver.md`。本卡只补了目录内的 `README.md`，未改动已有文件；W0-01 报告的遗留问题第 5 条也说明 `reports/README.md` 属于本卡。
2. **`pnpm format:check` 不覆盖 `docs/`。** 卡上的“格式通过 `pnpm format:check`”字面通过，但该命令只检查 `src/`，不能证明新文档符合 Prettier。本卡补跑了针对六份新文件的直接检查并通过，同时确认已有 `W0-01.md` 仍不符合 Prettier。建议把验收改为“新文档通过 `pnpm exec prettier --check <文件>`”，或新增 docs 格式脚本；本卡没有改 `package.json`，避免扩大范围。
3. **`status.md` 的行粒度。** README 第 11 节把 P2 至 P5 合并为阶段行；为了让 U-02 能按每张卡维护，本表按各阶段文档展开到每张卡（P2-01 至 P2-25、P3-01 至 P3-16、P4-01 至 P4-27、P5-01 至 P5-10），并按要求把 `P1-07a–d`、`P1-11a–g`、`P4-15 至 P4-26` 保留为一行。这与“行来自 README 第 11 节任务总表”的字面范围有出入；如果希望严格按总表的阶段行，可把 P2 至 P5 改回四行。
