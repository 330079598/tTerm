# GPUI 主题库与当前会话换肤验收

本批按两个用户操作验收，而不是以设置项数量验收：从外观页找到 Tauri 主题库中的任意配色；在已打开的工作区应用它，不重启或重连。

## 验收条件

1. **目录**：使用与 Tauri 相同的 `src/assets/themes/catalog.json`，不另抄一份名单。当前目录有 695 个主题；深色 `Dracula` 与浅色 `Catppuccin Latte` 均能找到。检查搜索、明暗筛选、无结果和取消，不把预览当成已保存。
2. **应用**：成功选择后，同一个窗口的设置、标题栏、已有分屏和新开的标签采用实际主题颜色。独立连接主题仍优先；原有终端实体和会话保持不变。
3. **持久化**：保存完整 `catalog:` 标识，重开可读；保存失败不替换当前配色。跟随系统开启时，只修改目标明暗槽，不自动关闭跟随。
4. **范围**：验证主题库选择和即时应用，不以此签收主题编辑、导入或所有页面的像素对齐。

## 协调者复验：这两项通过

在隔离的 GPUI 窗口测试中，保持两个真实本地 PTY 运行，依次搜索并应用 `catalog:Dracula` 和 `catalog:Catppuccin Latte`。两次切换后视图、绑定和终端模型身份均未改变，原会话可以继续执行命令。另有目录及配置文件读写、取消预览、保存错误、跟随系统的槽位、已有及新标签和连接独立配色的回归测试。未使用个人 SSH 连接。

生产设置页的独立无界面截图（800×600、2×）与 PTY 测试分开取证，不是桌面截屏：`cargo run -p tterm-gpui --example theme_library_capture --features tterm-gpui/automation -- --output target/parity/live-theme-audit/gallery`。前端六项、Rust 格式、严格 Clippy、默认并发全工作区测试及截图示例检查通过。独立 release 门禁：30 会话加载 p95 0.273 ms；30 MiB 全部应用并确认，用时 150.314 ms（199.58 MiB/s）。
