## 语义核对与偏差

- 匹配区间和单元格映射使用 UTF-16 code-unit 计数；Rust 的 `regex` 字节偏移先转换为 UTF-16。中文、宽字符、组合扩展和 emoji 的映射接口不依赖 xterm。
- Rust `regex` 不支持 JavaScript 的反向引用与环视。用户 regex 遇到不支持语法时编译返回 `invalid`，规则被跳过；不会放宽为错误匹配。内置地址模式在 Rust 中以等价可编译模式和显式边界处理实现。
- 配置归一化沿用前端的宽松规则：未知颜色变为 `null`，缺字段取默认，集合和规则按 50/100 上限截断，模式按 1000 个 Unicode scalar 截断（这里与 JS 的 UTF-16 slice 在极端代理对边界上存在一项未覆盖偏差）。
- `newHighlightId` 不复刻浏览器 UUID 字符串格式，只保证本进程唯一；持久化格式不依赖其形状。
