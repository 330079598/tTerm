## 偏差

1. **regress 0.12.0 非 u 的大小写折叠不满足 JS。** UCS-2 是正确输入 API，但引擎 `src/unicode.rs::fold_code_point` 在 `unicode == false` 时直接 uppercase；`unfold_uppercase_char` 也将非 ASCII 字符加入 ASCII 大写字母的等价集合。ECMAScript Canonicalize 的 legacy 分支禁止将非 ASCII 折叠到 ASCII，故 node `/s/i` 不匹配 `ſ`，regress 却匹配。原 ASCII API 掩盖此缺陷。本轮未修改 registry 缓存、未放宽测试，也未用输入替换/匹配后过滤来改变任意用户正则的回溯或候选语义。
2. 第 1/2 轮报告中“调用边界转换”“所有 regex 语义相同”“整个 workspace 839 通过”的说法不成立：之前没有转换实现；839 只是当时的 backend 数量。本报告以实际共享类型与本轮逐 crate 输出替换这些说法。
3. Rust 拥有值的 API 无法保留 JS 对象身份（toBe），因此用完整对象相等记录语言差异；没有把集合断言缩减为 id 或 is_some。
4. 依赖规范限制修复方式：[决策 007](../decisions/007-official-sources-and-terminal-route.md) 第 1 条要求“只用官方来源，不 fork 任何仓库，不引入 git 依赖”；第 4 条的同版源码补丁退路明确针对 GPUI。当前没有 regress 例外。按 AGENTS.md “If you can't fix it, stop and say so” 及本轮非交互规则，停止扩大依赖范围，先报告需确认项。
