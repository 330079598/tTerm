### 文件与行为

- `crates/tterm-terminal-view/src/view/element.rs`、`wheel.rs`：元素绘制、原生输入处理器安装与滚轮事件。元素定义路径为 `view::element::TerminalElement`，没有新增重导出。
- `keyboard.rs`：把 GPUI 按下、重复和释放交给 P0-28 编码器，读取最近快照的模式；优先字符输入时让路，已处理事件停止传播。连接焦点/窗口激活报告；输入后重置闪烁相位，普通输入清选区并滚回底部。
- `pointer.rs`：按网格原点、单元格尺寸和历史偏移定位；连接普通、词、行、矩形选区及右键扩展。先决定本地/上报，再调用已有编码器；同格移动去重，避免 Shift 本地点击产生孤立松开报告。Shift 左/右拖动本地选择，Shift 中键移动和滚轮保留 P0-28 策略。
- `clipboard.rs`、`paste.rs`：macOS 使用 Cmd+C/V，其他平台使用 Ctrl+Shift+C/V。复制模型选区文本；粘贴统一 CRLF/CR，移除除换行与 Tab 外的控制字符，普通模式用 CR，括号模式用 LF 并包裹 `ESC[200~`、`ESC[201~`。写入同一个会话输入通道。
- `composition.rs`、`ime.rs`、`input_handler.rs`：预编辑仅在视图保存，画背景与下划线且不换行；组合期间不画终端光标。选中范围始终为 `0..0`，标记范围按 UTF-16 计算，不暴露回滚文本。候选框使用窗口网格坐标及 shaped text 偏移；组合固定锚点，短暂隐藏光标沿用最后可见位置，超过 500ms 使用当前光标。关闭 macOS 长按重音菜单。
- `prepare.rs`：随重绘刷新输入锚点并使字符坐标失效。提交只发送一次 UTF-8，不走括号粘贴；观察到组合 Enter 时抑制确认键重放，鼠标选词提交后的下一次 Enter 仍可执行。失焦、隐藏和视图 `clear()` 清理本地组合。
- `input_tests.rs`、`pointer_tests.rs`、`ime_tests.rs`：新增 26 项 GPUI 测试，分别为 6、7、13 项；测试平台结果不代表实际系统输入法或剪贴板服务已验证。
- `crates/tterm-gpui/examples/terminal_view.rs`：更新说明。演示已有真实 PTY 和 `InputSink` 到 writer 的通道，本卡沿用它，没有新增 PTY 会话工程。
