### grep 说明

附件均保存命令和未经筛选的原始输出。State 注入扫描覆盖全仓 Rust 源码；状态查找扫描覆盖 src-tauri 与 crates。当前安全查找只出现在：

- Tauri 启动、窗口与退出回调：`lib.rs`。
- 路径、身份与窗口适配器：`app_paths.rs`、`app_identity.rs`、`window_state/mod.rs`。
- 平台适配器：`platform/tray_native.rs`、`platform/window.rs`。
- IPC 入口：`notification_permission`、`start_drag_out`、`sftp_external_edit_list`、`sftp_external_edit_release_tab`。

`rg -n '\.state\s*::' src-tauri/src crates --glob '*.rs'` 无输出（退出码 1）。没有后台任务通过 AppHandle 反查领域服务；Tracker 的延迟任务属于窗口适配层。
