## 追加验收：Windows 冷启动目录

GPUI 冷启动先恢复工作区，再按参数顺序为有效目录打开配置的默认本地 Shell。没有可恢复的标签时，有效目录不会附带额外空白标签；无效目录不打开，窗口列出对应路径。`--` 后允许以 `-` 开头的目录名；`--exec` 和 `--ssh` 保持原语义。

Windows 定向测试通过：含空格路径的真实 PTY 工作目录、恢复顺序、稳定 ID、最后标签激活、无效路径提示及普通启动回退。前端六项、Rust 格式及严格 Clippy 通过。默认并发的最终 `cargo test --workspace` 为 3497 通过、41 忽略；首跑曾有 4 个 hook 子进程用例失败，独立全量复跑通过，未改断言。Windows release 负载 p95 为 0.3321 ms，30/30 会话推进；30 MiB 全部确认用时 137.511 ms（218.16 MiB/s）。仅验收本轮 Windows 自动化，不替代固定 macOS 15 任务。

冷启动不含已运行实例的目录转发。只读检查发现本机 Explorer 的文件夹、背景、驱动器菜单均指向已安装程序，而非本次 GPUI 构建，未更改注册表。下一步在隔离 Windows 用户或虚拟机实际从 Explorer 打开目录，再在 macOS 从 Finder 验证；此前不签收系统入口、P3-11 整卡或 G2/G3。
