# 设置页：从原窗格修改回滚行数

按[决策 018](../decisions/018-workspace-settings-order.md)先走通一个日常操作，不提前宣告 P4-15 或 G2/G3 通过。实现基点是 `86c29e26`，工作分支为 `migrate/settings-scrollback-flow`；由 Pi + DeepSeek V4.1 Flash 实现，协调者独立复核。

| 步骤 | 要做什么 | 怎样验收 |
| --- | --- | --- |
| 设置外壳与搜索 | 在正式 GPUI 设置页接入侧栏、搜索和内容区，只暴露可用入口。复用核心搜索索引和翻译。 | 英文、中文查询均能找到回滚行数；空结果能清除；键盘和鼠标都能选择结果。 |
| 编辑与返回 | 沿用现有配置写入和订阅，验证合法值；失败不能显示保存成功。 | 从非均分的两个隔离 PTY 打开设置，确认保存后运行中的容量改变，重开读回；编辑没有向 PTY 泄漏输入，后台仍有输出，返回恢复原焦点和分屏比例。 |
| 画面对照 | 给原版生产组件补采同一查询和目标项；对照真正的 GPUI 渲染，而不是另外绘制示意图。 | macOS、800×600 内容区、DPR 2、dark/classic/100%、en-US，记录截图、布局和复现命令。分别报告已对齐部位、实测偏差和未迁移分类；不能以 `font` 的结果替代 `scrollback`。 |
| 合并门槛 | 协调者审差异、复跑行为测试、核对视觉证据。 | 前端六项、Rust fmt/严格 Clippy/workspace 测试、release 帧与吞吐两项均过。证据不齐留在工作分支，普通卡通过只本地合并，不推送。 |

全程使用隔离数据，不读取个人连接、密钥或正式配置。完整设置中心、其它 B1～B4 场景和 G 关卡不在本卡范围内。
