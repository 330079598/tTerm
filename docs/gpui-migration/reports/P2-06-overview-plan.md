# P2-06 第二批：概览标记执行方案

起点为本地 `GPUI` 当前 HEAD。第一批已经通过滚动、滚动条重绘、滚动锚点和清历史内存验收；本批只接入生产视图的概览标尺数据，不实现 P2-07 的搜索输入框、正则选项或结果导航。

## 实施

1. **命令标记。** 将已有 `CommandMarks` 的绝对行位置以只读快照暴露给视图；通过现有 OSC 133/633 报告路径更新。概览标记必须随滚动历史淘汰、清除历史、备用屏切换和窗口重排同步失效或平移，不复制另一套命令状态机。
2. **搜索标记接口。** 为未来 P2-07 留下明确的只读匹配行输入（空集合也可），但不伪造搜索结果、不绘制不可用的交互入口。若现有搜索模型尚未能提供稳定绝对行，记录依赖关系而不是硬编码。
3. **绘制与几何。** 在现有 10px 滚动条轨道内绘制命令/搜索标记，使用同一 `ScrollbarGeometry` 的历史坐标换算；高密度标记合并或限制绘制次数，不能影响滚动帧预算。标记不改变滚轮、拖拽或历史容量。

## 验收

- 单元测试覆盖：三个命令 mark 的位置、历史淘汰后的平移/丢弃、`ED 3`/RIS 清除、备用屏不污染、空标记和密集标记。
- 视图测试使用真实生产 `TerminalView` 和合成 PTY 输出，确认标记随顶部/底部拖拽和追加输出移动；不以截图专用 ScreenView 代替。
- 对照原版同状态的概览区域截图/布局；若原版使用的颜色或标记形状不同，报告局部差异，不放宽整页门槛。
- 全量前端、Rust、release 帧/吞吐检查通过后才允许本地合并。本批通过不等于 P2-06 或 G2 整卡通过；原生桌面手测仍单独记录。

只使用隔离测试数据，不读取真实连接、密钥或正式配置。Pi 只提交本地分支，不 push/merge；协调者验收后再决定是否合入。
