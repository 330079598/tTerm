### 当前报告协议、状态归属与续接规则

新报告为 `OSC 777 ; tterm-agent ; agent ; state ; session ; direct|broadcast ; percent-encoded-cwd BEL`，Windows/Unix 一致。无 session 的原状态报告仍兼容，旧仅带 session 的报告按广播认领。工作区仍只新增可选 `connection.agentResume`，没有新字段或 schema。

- **状态显示按 dev 原规则恢复：** `sessionOwners`、`AgentTracker.submit()`、10 秒 `AGENT_CLAIM_WINDOW_MS` 和 `terminalInput.ts` Enter 调用均恢复。新广播由窗口内第一个收到它的候选标签认领，一次 Enter 只认领一个新会话；其他标签忽略已被占用 ID，ended/reset/dispose 释放状态归属。`agentStatus.dev.test.ts` 原样恢复 dev 的四个共享后台状态用例。
- **direct 续接：** 本终端报告直接建立记录；不得覆盖另一个标签已占用的 ID。
- **broadcast 续接：** 只有新状态认领发生时，所有 tracker 中恰好一个在窗口内按过 Enter，且 hook cwd 与本标签 live shell cwd 均存在并匹配，才创建记录。Windows 路径忽略大小写、统一分隔符及扩展路径前缀；POSIX 路径大小写敏感。此条件只限制续接，不改变状态认领。窗口内两个及以上标签输入时，状态仍按 dev 规则处理，但不给任何标签续接记录。已消耗的 Enter 时间仍计入竞争，不能因状态认领先后漏掉竞争者。已保存的同 agent/session 后续广播正常更新；旧状态会话的后续广播不能覆盖另一个当前续接。idle/ended/prompt 清理续接。
- **cwd：** 首次记录优先 live shell cwd，缺失才取钩子 JSON 顶层 cwd，后续同会话保持启动目录。目录非空、长度不超过 16384 字节且不含控制字符；OSC UTF-8 百分号编码；恢复时再次经过 Rust 校验和实际 shell 转义。`hook_input.awk` 无新增依赖，Windows helper 使用现有 percent-encoding。
- **Outdated：** 当前脚本或可执行路径改变会显示 Outdated；只有用户安装/更新才改写钩子，保留其他钩子。共享后台广播认领与状态分离的实现和测试见本轮小节。

### 其他 shell 的同形字符检查

POSIX sh/bash/zsh 的引号分隔符是 ASCII 单/双引号；fish 单引号内特殊字符为 ASCII 单引号与反斜杠，已有分别转义；cmd 以 ASCII 双引号界定目录，并保守拒绝 ASCII `" % & | < > ^ !`。它们均未把 PowerShell 的四种弯单引号视为分隔符。本轮 `other_shells_keep_unicode_quote_lookalikes_literal` 固定弯单/双引号和全角引号保持字面值的输出，未发现同类同形字符分隔问题。该结论基于上述语法及构造测试；本轮只有 Windows PowerShell 原生解析器得到实际验证，bash/zsh/fish 的真实 shell 执行、cmd 实际执行仍未验证，不将字符串断言冒充平台实测。
