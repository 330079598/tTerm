# P2-19 第一批：只读恢复旧快照

2026-11-24，Windows 工作区自动回归。只对当前数据根中普通启动恢复出来的标签生效；不会搜索其他客户端的数据目录。关闭「重启后恢复终端内容」，或者通过 `--exec`、`--ssh` 启动，不导入快照。

- [合成样本](assets/P2-19/legacy.json)由旧版生产 `serializeTerminal` 和锁定的 xterm 插件生成。样本包含滚出屏幕的首行、红色文本、中文及提示符，不含用户会话。
- 读取 `scrollback/<tab-id>.gz` 时不清理文件；GPUI 保存工作区布局也不清理旧快照。损坏、缺失或超限只影响该标签的历史，不阻止新会话。每个文件压缩前后各限制 32 MiB，启动时跨标签保留的解压文本共限 64 MiB。
- 仅把字符、颜色及旧序列化器使用的绘制操作送入模型。临时解析器在新 PTY 接入之前结束，历史不能写 PTY、应答查询、改标题或写剪贴板；恢复分隔行之后是新会话的输出。
- `cargo test --workspace legacy_snapshot_startup` 从隔离数据根读取真实 SQLite 与 gzip；验证三个标签的归属、历史、颜色、损坏与缺失时仍可启动、开关与显式启动的绕过路径、新 PTY 命令结果，以及保存后文件集合和内容不变。模型和读取器另有针对控制串、截断、校验及大小边界的回归。

这不是两套桌面客户端的人工互操作验收，也未引入原生写入格式或签收 G2。
