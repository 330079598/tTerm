# P3-08：macOS 分屏快捷键验收（2026-11-26）

在隔离的 GPUI 桌面窗口里打开两个本地 Shell，通过项目调试接口向活动窗口发送快捷键和终端输入。用截图、实际 Shell 输出和隔离数据库中的布局交叉核对，不以标签标题判断会话是否存活。

| 场景 | 操作与结果 |
| --- | --- |
| 放大与还原 | 左窗格按 `⌘⌥Enter` 后占满窗口；再次按下恢复双栏。操作前后保存的比例均为 `[0.4244802590184564, 0.5755197409815436]`。 |
| 键盘焦点与输入隔离 | 双栏时用 `⌘⌥←`、`⌘⌥→` 切换。放大左侧后按向右的快捷键，活动标题仍为左侧；新命令只在左侧运行。还原后切到右侧，得到 `ROUTE-R-62004-62004-ZOOM-unset`，未收到左侧设置的变量。 |
| 解除分屏 | 在右侧按 `⌘⌥` 加反斜杠，保持右侧活动。切换两个独立标签后分别得到 `SINGLE-R-62004-62004` 和 `SINGLE-L-62003-62003-ZOOM-only-left`。两个 PID 均与操作前一致；保存的布局为两个各含一个窗格的组。 |

本批三项通过。另有 18 项 `split_session_tests` 回归通过。此结论仅适用于本轮 macOS 分屏桌面场景，不替代其他平台复核或 G3 签收。
