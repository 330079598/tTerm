持久化测试覆盖的关键读取规则：

- 当前格式只由数值 `version === 2` 选择；字符串 `"2"`、版本 1、缺失版本都按
  Dockview 读取。
- `read_pane_node` 逐节点检查；非对象、未知 `type`、坏 `orientation`、缺失或
  非数组 `children`/`sizes`、空 `children`、含坏子节点的 split 都使所在组被
  丢弃，其他组保留。
- 每个 `sizes` 项按 `typeof size === "number" && size > 0` 判断，否则为 `0`；
  多于子节点数量的尺寸忽略，少于子节点数量的位置补 `0`。未知字段不进入模型。
- 当前格式中 `activeTabId` 不是字符串时读为空字符串；`zoomedTabId` 不是字符串
  时视为缺失。恢复时再删除不存在于该组的 active/zoom，并用第一个窗格补齐
  active。
- Dockview 的 `leaf` 只接受字符串 `views`，`activeView` 必须在前者中，否则用
  第一个非空 view；同一组的 `id` 后写覆盖先写；`branch` 的非法子节点跳过，
  没有有效子节点时整支丢弃；`activeGroup` 为空时回退到第一支的 front。
- 旧样例 `{"root":"tab-1"}` 不含 `grid`，按 Dockview 读取为空组；这是第 1 组
  的 `resume_compatibility_tests.rs` 里保留的真实旧形状。

## 正则审计

oracle 的 `audit()` 对每个模式分别执行
`new RegExp(pattern, flags).test(positive)` 与
`new RegExp(pattern, flags).test(negative)`，没有复用带状态的
`lastIndex`。Rust 侧使用 workspace 已有的 `regress = 0.12.0`，并在
`tterm-core` 中启用 `utf16`；因此字符集、环视/反向引用和 ECMAScript
空白语义由同一个 ECMAScript 引擎处理，而不是 Rust `regex` 的近似实现。
测试
`tterm_core::workspace::tests::regex_audit::oracle_regex_audit_matches_the_engine_used_by_the_port`
逐项断言 node 的布尔结果与 `regress` 相同。

| # | 正则 pattern | flags | node 正例（结果） | node 反例（结果） | Rust 对应 | 等价原因 |
| ---: | --- | --- | --- | --- | --- | --- |
| 1 | `\\` | `g` | `a\b` → true | `ab` → false | `local_tab_title::comparable_path` 的 `path.replace('\\', "/")` | 目标是单个反斜杠；全局替换每个反斜杠为 `/` 与所测正则一致。 |
| 2 | `^/([A-Za-z])(/\|$)` | — | `/c/Users` → true | `/1/Users` → false | `GIT_BASH_DRIVE`（`comparable_path`） | `regress::Regex` 使用相同捕获组与反向引用语法，`replace(..., "$1:/")` 只替换首个匹配。 |

| 4 | `^[A-Za-z]:` | — | `C:/Users` → true | `1:/Users` → false | `DRIVE_PREFIX`（`comparable_path`） | 仅判断开头两个 ASCII 字符；`find` 与 `test` 都只关心是否存在。 |
| 5 | `[\\/]+$` | — | `C:\Users\\` → true | `C:\Users` → false | `directory_title` 的 `trim_end_matches(['\\','/'])` | 去掉末尾连续的 `/` 或 `\`，与正则的字符类加 `+$` 相同。 |

## 空字符串真假审计

TS 中 `if (x)`、`x && ...`、`x || ...` 把 `""` 当作假值；Rust 的
`Option` 只表示“缺失”，`Some("")` 仍是真值。下表列出本轮涉及的判断点。
凡是 TS 依赖空字符串真假的位置，Rust 都显式检查了空值；只有 TS 明确把空字符串
当成合法值的位置保留 `Some("")`。

| 位置 | TS 语义 | Rust 处理 | oracle/测试证据 |
| --- | --- | --- | --- |
| `getFallbackTabId` | `activeTabId ?`；空字符串或 `null` 不查上一组 | `active_tab_id.filter(!is_empty())` | `oracle_treats_empty_ids_and_zooms_as_falsy` |
| `getVisiblePaneIds` | `activeTabId ?`；`group.zoomedTabId ?`；空值分别返回 `[]`/全部窗格 | 同样的非空过滤 | `oracle_treats_empty_ids_and_zooms_as_falsy`、`visibleEmptyZoom` |
| `removeTabsFromGroups` | `group.zoomedTabId && ...`；空字符串结束缩放 | `filter(!is_empty() && contains)` | `oracle_matches_tree_and_group_removal_edges` |
| `serializeTabGroups` | `group.zoomedTabId && ...`；空字符串不写出 | `filter(!is_empty() && contains)` | `oracle_serializes_constructed_groups_byte_for_byte` |
| `restoreTabGroups` | 空 `zoomedTabId` 不能成为恢复后的缩放窗格 | 同一过滤 | `oracle_round_trips_every_saved_layout_byte_for_byte` |
| `localShellTitle` | `distro?.trim()` 后 `distro \|\| shellName`；空白发行版回退 shell，空 shell 名仍可为结果 | `js_trim` 后 `filter(!is_empty())`，否则使用 `Option` | `oracle_matches_local_shell_titles_and_tooltips` |
| `runningCommandTitle` | `tab.autoTitle ?` 与 `command && commandTitle`；空命令不产生标题 | `unwrap_or(false)`；`command_title` 对空串返回 `None` | `oracle_matches_running_command_titles` |
| `commandTitle` | `if (!program)`；trim 后没有程序返回 `null` | `program.is_empty()` 返回 `None` | `oracle_matches_utf16_command_titles_and_regex_edges` |
| `withLocalCwd` | `tab.autoTitle && cwdTitle(cwd)`；空 cwd 不生成目录标题，但 `cwd` 仍写回连接 | 标题用 `cwd.filter(!is_empty())`；连接仍保存空字符串 | `oracle_matches_with_local_cwd` |
| `distinctLocalTitles` | `tab.autoTitle && cwd ? ...`；空 cwd 不进入分组 | 过滤 `cwd.is_empty()` | `oracle_matches_distinct_titles_and_identity` |
| `tabTooltip` | `filter(part => part && part !== tab.title)`；空 detail 部分丢弃 | `!part.is_empty()` 过滤 | `oracle_matches_local_shell_titles_and_tooltips` |
| `resolveTabIcon` | `agent && config.agents`；空 agent 不采用 agent 图标 | `agent.filter(!is_empty())` | `oracle_matches_resolved_icons_badges_and_picked_colors` |
| `shellsForSettings` | `if (key && !keys.includes(key))`；空/空白 shell key 跳过 | `!key.is_empty()` 过滤 | `oracle_matches_normalized_configs_and_shell_lists` |
| `normalizeTabIconConfig` | `if (valid && shellKey(key))`；空对象键跳过 | `!key.is_empty()` 过滤 | `oracle_matches_normalized_configs_and_shell_lists` |
| `normalizeTabIconStyle` | `color === ""` 是合法颜色并转为 `""` | `Some("")`，不把空颜色当缺失 | `oracle_matches_shell_keys_and_normalized_styles` |
| `normalizeSavedSshTab` | `isDistroId("")` 为假；空发行版被删除 | `filter(is_distro_id)` | `oracle_matches_serialized_configs_and_helper_results` |
| `removeTabsFromState` | 空 tab id 与空 preferred/active id 是有效字符串，不按 falsy 过滤 | `Option<&str>` 与精确字符串比较，空串仍可匹配空 id | `oracle_matches_remove_tabs_from_state` |
| `ensureTabDefaults` | `??` 保留显式 `false` 和 `0` | `Option::unwrap_or` 保留 `Some(false)`/`Some(0)` | `oracle_matches_ensure_tab_defaults` |

## UTF-16 证据

`local_tab_title` 的 `utf16_len` 使用
`value.encode_utf16().count()`；命令标题的 `MAX_COMMAND_TITLE_LENGTH = 20`
按 UTF-16 码元而不是 Rust 的 UTF-8 字节或 Unicode 标量判断。oracle 直接执行
真实 TS，因此下面这些期望值不是从 Rust 推出来的：

- `commands` 中的 `echo 😀😀😀😀😀😀😀`（7 个 emoji）保留整串；再加一个
  emoji 后长度超过 20，期望只剩 `echo`。这同时验证代理对按 2 个 UTF-16
  单位计数。
- `commands` 包含 `echo 汉字汉字汉字汉字汉字汉字` 与
  `echo e\u0301e\u0301...`（组合字符），验证中文和组合字符不会被按 UTF-8
  字节截断。
- `directories` 包含 `/a/😀`、`/a/e\u0301`、`/工作/项目/`、`C:\用户\项目\`；
  `C:\ΟΣ`/`c:\ος` 与 `C:\İ`/`c:\i\u0307` 验证 Windows 路径的小写化结果。
- `distinct` 包含 `/a/😀/src` 与 `/b/😀/src`、以及组合字符目录，验证同名目录
  后缀按码元拼接后仍能区分。
- `shellKeys` 包含 `Σ`、`ΟΣ`、`ΣΣ`、`İ`、`ẞ`，`legacyTitles` 包含中文旧标题
  与全角 `Terminal-０`；期望值全部由 node 生成。
- `shellsForSettings` 的保存项排序使用 `encode_utf16().cmp()`，与 JS
  `sort()` 的 UTF-16 码元顺序一致，而不是 Rust 字符串的 Unicode 标量顺序。

## 偏差

- `directoryTitle`、`distinctLocalTitles` 等 TS 函数读取模块级异步 `home`；
  Rust 改为显式 `home_directory` 参数。这样纯函数不依赖平台调用顺序，P3 在
  home 加载完成后一次性传入即可；`nameLocalTab` 等异步入口仍不移植。
- 不移植 `detectLocalShellName`、`localShellName`、`nameLocalTab`、
  `refreshSavedLocalTabs`。它们调用 Tauri `invoke`、平台 home 目录或有异步
  生命周期，属于 P3/平台适配层；纯部分已由 `localShellTitle`、
  `directoryTitle`、`withLocalCwd`、`localTabTitle` 的其余函数提供。
- 第 1 轮误将 `TabsState`、`TabsAction`、`tabsReducer` 归为 React 专属部分。
  第 2 轮改为完整移植纯状态及 reducer；不移植的只有 `useTabs.ts` hook。
  P3 工作区实体直接调用 `tabs_reducer`，不必重新组合这些转换。
- `SavedTabGroup.active_tab_id` 是 `Option<String>`，因为 TS 的空 split
  `paneIds[0]` 是 `undefined`，`JSON.stringify` 会省略该键；`None` 正好
  对应省略，不能用一个空字符串替代。
- `Tab.distro_id` 保留为 `Option<String>`：TS 的 `DistroId` 是联合类型，但
  已保存/旧数据可能有未知字符串；读取模型必须宽松，合法性在
  `normalizeSavedSshTab` 处检查；直接继承图标仍按 TS 接受未知非空字符串。
  `Tab` 与 `TabConnection` 使用手写宽松 serde，保留原始有序字段作为 typed view
  的底层数据；未知 shell、错误类型、未知键和缺失键均不会导致整份会话失败。
- TS 的 `toBe` 对数组/对象比较引用同一性。Rust 使用拥有型值和结构相等，
  oracle 另外记录 `same`、`sameAfter`、`changed` 等布尔值；这些布尔断言
  与值断言共同覆盖 TS 的引用语义。拥有型 API 无法提供 Rust 的同一对象引用。
- TS 的模板字面量/联合类型（`DistroTabIcon`、`BrandTabIcon`、`AgentTabIcon`、
  `TabIconChoice`）在 Rust 中用字符串加 `is_*`/归一化校验表达，没有另造一套
  运行时模型；合法取值域与 TS 一致。
- `TabConnection` 中只由后端/未来功能使用的复杂 payload（`jump_hosts`、
  `proxy`、`serial`、`agent_resume` 等）用 `serde_json::Value`，因为它们
  本轮没有领域逻辑；字段名和可选性仍按 `Tab` 的 camelCase 形状保留。
- `pickedLogoColor` 的 TS 参数类型是封闭联合；运行时传入未知
  `logo:<unknown>` 会因查表而抛错。Rust 的 `&str` 入口没有抛错路径，未知
  brand 返回 `Some("")`（合法 brand 的颜色语义）；这是类型域外的防御性
  差异，合法 `TabIconChoice` 行为一致。
- Rust 的 `String` 不能表示未配对 UTF-16 代理项；本轮所有测试输入都是真实
  TS 能产生的配对代理项、中文、emoji 和组合字符。若未来需要从任意 UTF-16
  输入恢复未配对代理项，需要使用现有的
  `crates/tterm-terminal/src/js_text.rs` 的 lossy/unit helper，不能在核心
  `String` 中无损表示。
- 第 1 组遗留的 `tab_navigation::localeCompare` 说明继续有效：该模块在
  第 1 组已完成，本轮没有改变它的实现或测试。

### 读取字段审计

`Tab` 与 `TabConnection` 保留一套模型，所有字段的原始 JSON 都存入有序 map。
typed view 只投影可识别值，不把投影失败当作读取失败。序列化以原始 map 为起点，
只有显式修改过的字段才替换；非索引键保留顺序，索引键按 JS Object.keys 排序。
数字递归使用 `workspace/js_number.rs` 格式化，字符串/布尔/null 按 JSON 写出。

| 字段 | 读取及规范化策略 |
| --- | --- |
| `id`、`title`、`type`、`isActive` | 缺失和错误类型原样保留；typed view 的缺省值不回填持久化 JSON。未知 type 使用 `TabType::Unknown`，不会误当作 terminal。restore/activate 明确写入布尔 isActive。 |
| `iconStyle`、`distroId` | 原始读取保留；仅 SSH/本地会话规范化时，分别调用真正的 style 校验、`is_distro_id`；无效字段被省略，其他字段保留。部分有效 style 只保留有效子字段。 |
| `hasConnected`、`sessionNonce`、`connectionHeaderPinned` | 原始错误类型保留；ensureTabDefaults 在 Value 层按 `??` 仅替换 null/缺失，page 分支明确覆盖 hasConnected/sessionNonce。 |
| `pid`、`isModified`、`icon`、`duplicateBaseTitle`、`autoTitle`、`shellName`、`quickConnect`、`quickConnectAuth`、`settingsSection`、`settingsRequest`、`remoteFile` | 非目标字段不规范化，负 pid、分数、错误类型也不丢弃。local shellName 仅在 JS falsy 时填入平台已解析的 shell 名。 |
| `connection` 及其全部已知字段 | 宽松 typed view；未知 terminalShell（如 nushell）、字符串 port（如 "22"）、未知 auth/type、null 与其他错误类型都保留。`saved_field` 可读取 typed enum 以外的原始值，不会让 Vec<Tab> 失败。 |
| 任意未知顶层/connection/嵌套键 | 读取与写回都保留；测试含前/中/末未知键、嵌套对象、数组与 null。 |

`normalize_saved_local_tab` 是新增的纯平台边界 helper：接收平台已解析的 shell 名，
只实现 refreshSavedLocalTabs 的字段规范化部分，不冒充异步探测或旧自动标题的完整迁移。
异步 shell 探测、home 加载及 nameLocalTab 仍由 P3/平台层提供。reducer 的 distinct
标题调用沿用纯标题 API 的无 home 输入；平台 home 加载后按既有显式参数入口刷新标题。
