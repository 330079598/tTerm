# P3-08：macOS 布局模板双向验收（2026-11-26）

在两个桌面客户端的隔离配置中测试。发送端通过界面命名、保存布局，接收端从自己的“已保存布局”中选择并应用。两者之间原样复制 `panes.templates` 中的模板记录，不传递会话数据库或 PTY。

| 方向 | 操作和观察 | 结果 |
| --- | --- | --- |
| GPUI → Tauri | 将 `GPUI-42x58` 应用到已有三个窗格的 Tauri 标签。变为左右两栏（约 42.45% / 57.55%），多出的窗格移到独立标签。保留的 Shell 在应用前后返回相同的变量和 PID `49913`。 | 通过 |
| Tauri → GPUI | 将 `Tauri-Nested3` 应用到只有一个本地 Shell 的 GPUI 窗口。原窗格保留在左侧，占 60%；右侧占 40%，上下各半。 | 通过 |

另以只读方式检查两个接收端各自保存的工作区：忽略仅属于本地会话的 `tabId` 后，嵌套次序、方向和未取整的比例均与发送端模板完全相同。开始时尝试用仅含模板的 JSON 代替完整 Tauri 配置，因缺少必填 `theme` 被拒；上表为使用完整配置后的复测结果。

本次验证的是模板格式及桌面应用效果，不是配置自动同步、跨客户端迁移运行中的 Shell 或 Windows/Linux 桌面验收。
