- `backup/service.rs`、`backup/remote/service.rs`：本地及 WebDAV command 的编排。归档直接使用现有 `build_archive_for_version`，版本由入口从现有 AppIdentity 提取。删除 payload collection 中原本未使用的 AppHandle 参数。自动备份、导入前备份、WebDAV retention 与上传锁语义保持原样。
- `sync/service.rs`：同步设置和执行编排；原有同步锁、busy/disabled/locked 状态、三方合并、恢复备份及应用顺序不变。内部恢复备份和 WebDAV target 只接收版本字符串等具体依赖。
- `themes.rs`：command 委托领域函数处理主题导入及替换。
- `db` 原本不含 Tauri 类型；`fonts` 原本已经只把字体扫描交给阻塞函数；两者无需修改。
- `scripts/migration/command-signatures.*`：修复生命周期单引号的解析及去掉参数名中的 `mut`，补充回归测试，详见“偏差”。

## 偏差
