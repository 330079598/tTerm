## 方案与执行

1. 以 React 的实际设置路由为目录，建立[14 页清单](../settings-inventory.md)，按控件、存储与视觉证据列出差距，不添加不能操作的侧栏入口。
2. 设置页编辑名称、程序和参数；保存时重读配置，按 ID 更新而不是用旧快照覆盖。写入成功才更新界面读到的配置，失败保留草稿以便重试。
3. 标签栏 `+` 使用同一份配置列出 Auto 与未隐藏的自定义条目。选中条目在新标签启动；Esc 不创建会话；直接新建标签的快捷键保持原行为。

协调者写方案与验收，使用 pi agent + DeepSeek v4.1 Flash 分派清单、设置、启动器。前两项由执行者交付；启动器任务停滞后，由协调者接手实现并补真实 PTY 回归。
