### 参照与比较口径

使用现有 `@xterm/xterm 6.0.0`、`@xterm/addon-serialize 0.14.0`、`@xterm/addon-unicode11 0.9.0`。脚本严格检查这三个版本。加载 Unicode11Addon 后设置 `activeVersion = "11"`，与 `src/components/TerminalTab/openTerminal.ts` 一致。列/行取每个录制中的 resize，回滚容量两端均为 12。

SerializeAddon 保存结束屏幕的 ANSI 文本与样式，`scrollback: 0`。它不会保留 OSC 8 链接目标，因此另存语义 sidecar，避免只比较序列化字符串而漏报链接。sidecar 逐格保留 UTF-8 文本、宽度、前景/背景（默认/索引/RGB）、粗体/暗淡/斜体/反色/隐藏/删除线、五种下划线、下划线颜色、链接 id/URI，另比较光标、活动屏幕和有序应答。公开 buffer API 没有完整下划线/链接信息，脚本只读固定版本的扩展属性和 OSC 链接服务；无源码复制。

归一化仅处理等价表示：空白与显式空格、宽字符占位、ANSI 命名色与同索引色、未启用下划线时无视觉作用的下划线色。默认色保持语义值，不映射主题像素。原始 `.screen`、`.ansi` 与每条差异都提交；`.diff` 不由生成脚本更新，任何新增、消失或变化的差异都会使测试失败。回滚历史只用于驱动场景，比较对象为结束时活动屏幕，不宣称比较了完整历史或字体像素。

### 窗口回放与原始时间

命令与全部原始输出：`assets/P0-11/window-output.txt`；16 张截图在同目录，命名 `<夹具>-fast.png`、`<夹具>-original.png`。已逐组查看截图，实际为 640×360；只展示固定网格，其余区域为空背景。没有调用系统输入、没有驱动主程序窗口；example 自行消费固定夹具并通过公开 GPUI API draw/截图。

```powershell
cargo build --workspace --example terminal_replay
$evidence = 'docs/gpui-migration/reports/assets/P0-11'
foreach ($speed in @('fast','original')) {
  foreach ($name in @('session','unicode','alternate-restored','alternate-active','scroll-region','margin-motion','attributes','charset-replies')) {
    & target/debug/examples/terminal_replay.exe $name "--$speed" --screenshot "$evidence/$name-$speed.png"
    if ($LASTEXITCODE -ne 0) { throw "replay failed: $name" }
  }
}
```

代表性原始输出（全部运行退出码 0）：

```text
replay clock: 8 frames, recorded_us=600000, elapsed_us=13500
window comparison: 0 changed records, exact documented result
replay complete: 44x9, mode=fast
replay clock: 8 frames, recorded_us=600000, elapsed_us=601286
window comparison: 0 changed records, exact documented result
replay complete: 44x9, mode=original
```

原始时间模式以 `Instant` 对齐绝对微秒时间戳，过期帧立即执行；系统调度可能使帧迟到。最快模式取消时间等待，仍在 draw 后确认，因此这些耗时不是吞吐基准。两种模式的每组结束屏幕和 `.diff` 一致；逐对读取 PNG 字节比较得到 8 次 `True`。示例截图：[合成录制](assets/P0-11/session-original.png)、[Unicode](assets/P0-11/unicode-original.png)、[样式](assets/P0-11/attributes-fast.png)、[滚动区](assets/P0-11/scroll-region-fast.png)。

## 偏差

1. 前轮缺少 `@xterm/headless` 时按指令停止；评估者本轮明确确认直接用已有浏览器版 Terminal 的无 open 模式。现已采用，未安装 headless、未启动 Tauri。原停止条件已解除。
2. 按补充授权以合成时间戳字节流替代真实会话录制；存储的是现有 `load_recording` 给前端的二进制帧格式，不是读取或生成真实数据目录里的 `.tlog`。不宣称验证 JSONL 会话日志加载器。
3. SerializeAddon 不能单独完整导出超链接元数据，增加固定版本只读 sidecar，并保留原始 ANSI。比较范围仍为卡要求的结束文本与属性，没有扩展终端功能。
4. Windows example 开发过程中曾因在 Player 更新内触发 draw 发生实体重复更新 panic，已将 draw 移到更新外并完整重跑；失败运行未作为证据。
