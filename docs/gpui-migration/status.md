# 任务状态

本表由评估者按 [README 第 8 节 U-02](README.md#8-持续性工作) 维护，每张任务卡一行。执行者、分支与报告链接在领取和提交后填写。

状态只有六种：

| 状态   | 含义                                       |
| ------ | ------------------------------------------ |
| 未开始 | 还没有分支或报告                           |
| 进行中 | 已领取，尚未提交评估                       |
| 待评估 | 已提交报告，等待评估                       |
| 需修改 | 评估给出“需修改”，执行者在同一分支继续     |
| 通过   | 评估通过，可以合并                         |
| 推迟   | 按决策推迟到 G1 之后，并入后续卡或另行补做 |

平台按[决策 016](decisions/016-mac-windows-either.md)：卡在 macOS 或 Windows 上通过即可，另一个平台在状态里写“待补（决策 016）”；Linux 的验收项写“推迟（决策 016）”。
