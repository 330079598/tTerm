# 任务状态

本表由评估者按 [README 第 8 节 U-02](README.md#8-持续性工作) 维护，每张任务卡一行。执行者、分支与报告链接在领取和提交后填写。

状态只有五种：

| 状态   | 含义                                   |
| ------ | -------------------------------------- |
| 未开始 | 还没有分支或报告                       |
| 进行中 | 已领取，尚未提交评估                   |
| 待评估 | 已提交报告，等待评估                   |
| 需修改 | 评估给出“需修改”，执行者在同一分支继续 |
| 通过   | 评估通过，可以合并                     |

行取自 [README 第 11 节任务总表](README.md#11-任务总表)：W0、P0 与 P1 按表内逐行列出；P2 至 P5 在总表中合并为阶段行，本表按各阶段文档展开到每张卡。总表或阶段文档中合并成一组的小组保留为一行：`P1-07a–d`、`P1-11a–g`、`P4-15 至 P4-26`。G0 与 G1 是关卡，总表列出了它们，本表一并保留；G2 至 G4 的结论写入 `decisions/`，不在此表。
